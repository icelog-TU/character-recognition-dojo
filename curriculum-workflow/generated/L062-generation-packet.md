## Approved Sentences

1. 我在水邊看山上的鳥
   - Spoken: 我在水邊看山上的鳥
   - Focus: 山
   - Image note: 小女孩站在水邊，看向山上飛着或停着的鳥。
2. 一隻小鳥飛到高山上
   - Spoken: 一隻小鳥飛到高山上
   - Focus: 高
   - Image note: 一隻小鳥正往很高的山上飛，山要看起來高。
3. 人少的山邊比水邊好
   - Spoken: 人少的山邊比水邊好
   - Focus: 少
   - Image note: 同一畫面比較山邊和水邊：水邊人很多很擠，山邊人少、安靜、舒服，讓山邊比較好很清楚。
4. 你和我一起去門前
   - Spoken: 你和我一起去門前
   - Focus: 去
   - Image note: 兩個小孩一起走向一扇門的門前，動作要清楚是在一起去門前。
5. 男孩女孩也來看書
   - Spoken: 男孩女孩也來看書
   - Focus: 來
   - Image note: 男孩和女孩一起來到圖書館或閱讀角看書，旁邊可以有另一個孩子已經在看書，表示他們也來看書。
