# Review Module Requests

Use this folder for review module request files such as `R001.json` and `R002.json`.

Review modules are not numbered lessons:

- Use `R###` ids, not `L###`.
- Do not include `newChars`, `zhuyin`, or single-character `charAudio`.
- Store final assets under `public/assets/reviews/R###/`.
- Keep new-character lessons in `curriculum-workflow/lesson-requests/L###.json`.
